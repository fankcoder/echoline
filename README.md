# EchoLine

一个面向影子跟读和精听练习的双语视频播放器原型。

## 本地运行

```bash
npm install
npm run dev
```

打开 `http://localhost:5173/`。当前版本已完整适配示例 DeepLearning.AI 课程，视频使用课程 CDN 的 HLS 流，英文与中文逐句字幕已经保存在 `public/`。

## 已实现

- URL 导入示例课程
- 89 句双语时间轴与点击跳转
- 学习模式：原句、复述倒计时、自动复播、手动下一句
- 播放速度、音量、进度和全屏控制
- 划词语境释义、点击收藏与本地生词本
- 悬停免费词典查询：中文释义、音标、词性、英文解释与例句，本地缓存查询结果
- 生词按收藏顺序每 10 个分组，可任选一组并随机复习
- 一键隐藏视频画面，音频、字幕同步和学习计时保持运行
- 独立课程管理页：创建和切换课程、查看视频学习进度、进入学习；播放器可保存当前视频并按规范化 URL 自动去重
- 累计有效学习时长、已学视频和已学习课程统计
- 桌面和移动端响应式布局

## 数据与接口

当前原型不需要后端，生词本、课程集、词典缓存和学习统计均保存在浏览器 `localStorage`。查词使用免费的 [Free Dictionary API](https://dictionaryapi.dev/) 获取英文词典信息，并用 [MyMemory](https://mymemory.translated.net/) 补充中文词义；示例课程的中文字幕已经随项目保存，不会在播放时调用 LLM。

## 当前边界

其他需要登录的课程页不能由普通网页直接读取浏览器登录态。产品化时应增加一个浏览器扩展或桌面采集器，把用户有权访问的媒体清单和字幕安全地传给播放器。多人同步、跨设备数据和按上下文生成翻译时，再增加账号与后端服务。
